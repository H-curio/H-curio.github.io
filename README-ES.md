# Descripción General

Este portfolio fue construido como un espacio técnico personal y una plataforma de presentación profesional.

Combina:

- aprendizaje en ciberseguridad,
- investigación OSINT,
- administración Linux,
- prácticas de pentesting,
- experimentación IoT y ESP32,
- investigación NFC/RFID,
- desarrollo web,
- writeups técnicos y laboratorios.

El objetivo es documentar progreso real mediante proyectos, laboratorios, certificaciones y práctica técnica.
